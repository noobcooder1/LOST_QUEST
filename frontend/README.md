# LOST QUEST 프론트엔드

React + TypeScript + Vite를 사용한다. 회원가입·로그인, 물품·사진 등록, 검색·매칭, 반환·QR·경험치와 알림은 Spring Boot API에 연결되며 회원의 기록은 MySQL에 저장된다. 경찰청 정보는 외부 공공데이터 API를 통해 조회한다. 사진 특징 분석 화면은 아직 시뮬레이션이다.

## 실행

백엔드와 MySQL을 먼저 실행하고 다음을 진행한다.

```bash
cd frontend
npm ci
npm run dev
```

의존성이 이미 설치되어 있으면 `npm ci`는 생략한다. `.env.local`에 `VITE_API_BASE_URL=http://localhost:8080`을 설정한다. 기본 접속 주소는 `http://127.0.0.1:5173`이다.

전체 실행 명령은 [macOS 실행 가이드](../계획서및회의록/10_macOS_전체_실행_가이드.md), 저장 구조와 반환 이용 방법은 [DB 저장 가이드](../계획서및회의록/11_이메일_검증과_전체_DB_저장.md)를 참고한다.

## 화면

| 경로 | 기능 |
| --- | --- |
| `/signup`, `/login` | 이메일 형식 검사, 회원가입·로그인 |
| `/register?type=lost`, `/register?type=found` | 물품과 선택 사진 등록, 습득물 소유 확인 질문 설정 |
| `/search` | LOST QUEST·경찰청 물품 검색 |
| `/matches` | 내 분실물 기준 서버 매칭 추천 |
| `/items/:id` | 물품 상세·반환 요청·내 습득물 확인 질문 설정 |
| `/returns/:id` | 소유자 확인, 승인 상태, QR 제시·코드 검증, 완료 기록 |
| `/admin` | 내 습득물 반환 승인·반려·최종 완료, 관리자 검토 |
| `/mypage` | DB 기반 등록·반환 기록, XP·업적, 매칭·활동 알림 |
| `/guide` | 이용 안내 |

반환은 요청자와 습득자 계정을 구분해 진행한다. QR 코드는 서버에서 검증하며 카메라 스캐너는 아직 제공하지 않는다. 브라우저 예시 물품·프로필·반환 데이터와 체험 초기화 기능은 현재 화면에서 사용하지 않는다. 기존 저장소는 삭제하지 않는다. 로그인 토큰만 브라우저 탭에 저장하며, 서버 실패 시 성공한 것처럼 로컬 기록을 만들지 않는다.

## 검증

```bash
npm test
npm run build
```

이전 브라우저 저장소 파서·체험 로직의 테스트는 과거 기록 호환성을 위해 남아 있으나 현재 앱의 저장 경로로 사용하지 않는다.
