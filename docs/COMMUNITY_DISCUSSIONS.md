# 독립 커뮤니티 게시판 — 2026-10-20

커뮤니티 글은 `community_posts`에 저장합니다. 분실물·습득물은 기존 `lost_items` / `found_items`와 물품 찾기 화면에 그대로 남으며, 커뮤니티 목록으로 복사하거나 합치지 않습니다. 물품 상세의 비공개 질문·신고·반환 절차는 기존 API를 유지합니다.

## 서버 적용

운영 환경의 JPA 기본값은 `validate`입니다. 새 서버를 시작하기 전에 DB를 백업하고 [추가 SQL](../계획서및회의록/SQL/06_커뮤니티_독립_게시판.sql)을 적용합니다. 개발 프로필의 `ddl-auto=update`는 새 테이블을 추가합니다. 이 변경에는 기존 물품/질문 데이터 마이그레이션이 필요 없습니다.

## 게시판 API

| 요청 | 인증 | 응답 |
| --- | --- | --- |
| `GET /api/community/posts` | 공개 | `{items: CommunityPost[], page: number, hasNext: boolean}` |
| `GET /api/community/posts/{id}` | 공개 | `CommunityPost` |
| `POST /api/community/posts` | Bearer JWT | `201 CommunityPost` |

목록은 `category`, `q`, `from`, `to`, `page`를 선택적으로 받습니다. 페이지는 0부터 시작하고 20개 단위입니다. 정렬은 서버 등록 시각 내림차순, 동일 시각에는 ID 내림차순입니다. `from` / `to`는 `YYYY-MM-DD` 형식의 **한국 시간 등록일**이며 양쪽 날짜를 모두 포함합니다. 검색은 제목 또는 본문에서 대소문자를 구분하지 않는 부분 일치이고 `%`, `_`, `!`도 일반 문자로 검색합니다. 검색어는 100자 이하, 페이지는 0–10000입니다. 필터를 함께 보내면 모든 조건을 적용합니다.

| `category` | 표시 이름 |
| --- | --- |
| `chat` | 자유·잡담 |
| `info` | 정보공유 |
| `question` | 질문 |
| `story` | 후기 |

JSON 글쓰기:

```json
{
  "category": "info",
  "title": "동네 분실물 보관소 이용 안내",
  "content": "운영 시간과 방문 방법을 공유합니다.",
  "linkedItemType": "found",
  "linkedItemId": 123
}
```

물품 연결의 두 필드는 함께 생략하거나 함께 입력합니다. 사진이 있으면 `multipart/form-data`의 `post` 파트에 위 JSON을 `application/json`으로 보내고 `image` 파트에 이미지 한 장을 보냅니다. 사진은 선택 사항이며 실제 디코딩 가능한 JPEG/PNG/WebP, 최대 10 MiB입니다. 작은 JSON 요청 한도는 16 KiB이고 multipart는 별도의 10 MiB 파일 / 11 MiB 요청 한도를 사용합니다.

응답 예:

```json
{
  "id": 1,
  "category": "info",
  "title": "동네 분실물 보관소 이용 안내",
  "content": "운영 시간과 방문 방법을 공유합니다.",
  "authorNickname": "이웃",
  "createdAt": "2026-10-20T01:00:00Z",
  "imageUrl": null,
  "linkedItem": {"id": 123, "type": "found", "title": "검은 우산"}
}
```

제목은 1–120자, 본문은 1–3000자의 일반 텍스트입니다. 공백만 있는 값, HTML, 공개 연락처는 기존 공개 게시글 규칙으로 거절합니다. 작성자·등록일은 서버가 생성합니다. 클라이언트의 작성자/등록일 값은 신뢰하지 않습니다. 글쓰기는 사용자별 분당 10회이며 초과하면 `429`, `Retry-After: 60`을 반환합니다.

물품 연결은 현재 공개된 LOST QUEST 사용자 물품만 허용합니다. 경찰청 외부 게시물이나 없는/숨김/삭제(CLOSED) 물품 연결은 허용하지 않습니다. 반환 완료 물품은 기존 물품 API에서도 공개되므로 연결할 수 있습니다. 연결 후 물품이 숨김/삭제되면 커뮤니티 글은 유지하고 `linkedItem`을 `null`로 반환합니다. 숨김/삭제된 물품 제목, 소유 확인 질문, 답변, 이메일 등의 비공개 정보는 응답에 복사하지 않습니다.

## 화면과 이동

- `/community`: 물품 목록과 분리한 이야기 목록. 전체/자유·잡담/정보공유/질문/후기, 제목·본문 검색, 최근 7일/30일/직접 지정 기간을 조합합니다. 조건은 URL에 유지되고 서버에서 20개씩 페이지를 조회합니다.
- `/community/write`: 커뮤니티 전용 카테고리·제목·본문·선택 사진 작성 화면. 로그인한 회원만 등록하며, 필요한 경우 본인이 등록한 물품을 선택해 연결합니다. 계정이 바뀌면 이전 계정의 작성 내용과 진행 중 요청의 화면 처리를 분리합니다.
- `/community/posts/{id}`: 공개 글 상세. 사진과 연결된 물품의 바로 가기 버튼을 표시합니다. 물품을 확인하고 돌아오거나 목록으로 돌아가도 원래 게시판 검색 조건을 유지합니다.
- `/search`와 `/register`: 기존 분실·습득 물품 찾기 및 등록. 물품 상세의 비공개 질문함도 유지합니다.

기존 물품 5개는 로컬 물품찾기에 유지되고, 새 커뮤니티는 독립 게시글이 등록되기 전에는 빈 게시판 안내를 표시합니다. 기존 물품을 커뮤니티 글로 자동 전환하지 않습니다.

2026-10-20 검증 결과: 프론트엔드 전체 545개, 백엔드 전체 401개 테스트 통과. 프론트엔드 프로덕션 빌드와 백엔드 패키징 완료. 로컬 MySQL에서 실제 글 저장, 복합 필터, 공개 상세, 물품 연결, 물품 목록과의 분리를 확인했고 임시 계정·게시글은 정리했습니다. 개발 서버를 새 백엔드로 다시 시작했으며, 320px 화면의 날짜 필터와 가로 넘침도 확인했습니다.
