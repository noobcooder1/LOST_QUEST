# LOST QUEST 발표자료 개발 기록

## 02. 백엔드 프로토타입

### 구현 목적

프론트엔드 프로토타입의 기능을 실제 서버와 데이터베이스 기반으로
전환하기 위해 Spring Boot 기반 백엔드 개발 환경과 기본 아키텍처를 구축하였다.

### 주요 구현

- Spring Boot 기반 REST API 서버 구축
- Controller → Service → Repository 3계층 구조 적용
- Entity와 DTO 분리
- User / LostItem / FoundItem 기본 데이터 모델 구성
- Spring Data JPA를 이용한 데이터 접근 계층 구현
- MySQL 데이터베이스 연동
- 공통 예외 처리 및 API 오류 응답 구조 구현
- Spring Security 기본 보안 설정
- CORS 설정을 통한 React 프론트엔드 통신 환경 구성
- 서버 상태 확인 API 구현
- 분실물/습득물 기본 조회 API 구현

### 사용 기술

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- Spring Validation
- MySQL
- H2
- Maven

### 핵심 설계

Controller, Service, Repository의 역할을 분리한 3계층 구조를 적용하였다.

API에서는 Entity를 직접 반환하지 않고 DTO를 사용하도록 구성했으며,
공통 예외 처리를 통해 API 오류 응답 형식을 통일하였다.

실제 운영 데이터베이스는 MySQL을 사용하고,
자동 테스트에서는 H2 인메모리 데이터베이스를 활용할 수 있도록
개발 및 테스트 환경을 분리하였다.

### 프론트엔드 연동

React 프론트엔드와 Spring Boot 백엔드를 서로 독립적으로 실행하고,
환경변수를 이용해 백엔드 API 주소를 설정하도록 구성하였다.

실제 실행 환경에서 React → Spring Boot API 요청과
CORS 처리가 정상적으로 동작하는 것을 확인하였다.

### 테스트 및 검증

- Spring Boot 프로젝트 빌드 성공
- 백엔드 자동 테스트 통과
- 실제 MySQL 데이터베이스 연결 확인
- JPA를 통한 테이블 및 관계 생성 확인
- Spring Boot 서버 실제 실행 확인
- `/api/health` 요청에 HTTP 200 응답 확인
- 분실물/습득물 조회 API 정상 응답 확인
- React에서 Spring Boot 상태 확인 API 실제 호출 성공
- CORS 요청 정상 처리 확인

### 발표에서 강조할 점

프론트엔드 프로토타입에서 사용하던 가상 데이터를 실제 서버와
데이터베이스 기반 기능으로 전환하기 위한 백엔드 기반을 구축하였다.

특히 단순히 API 코드만 작성한 것이 아니라
React → Spring Boot → MySQL로 이어지는 전체 통신 구조를
실제 환경에서 검증하였다.
