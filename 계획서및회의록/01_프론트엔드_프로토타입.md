# LOST QUEST 발표자료 개발 기록

## 01. 프론트엔드 프로토타입

### 구현 목적
백엔드 개발 전 전체 사용자 흐름과 UI/UX를 검증하기 위해
React 기반 프로토타입을 먼저 구현하였다.

### 주요 구현
- 분실물/습득물 등록
- 물품 검색 및 상세 조회
- AI 매칭 결과 UI
- 소유자 확인
- QR 반환
- 경험치/레벨/업적
- 관리자 화면
- 반응형 PC/모바일 UI

### 사용 기술
- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Vitest

### 핵심 설계
초기에는 Context와 LocalStorage 기반 데모 데이터를 사용하여
백엔드 없이도 전체 사용자 시나리오를 실행할 수 있도록 구성하였다.

### 발표에서 강조할 점
프론트엔드 프로토타입 → 백엔드 구축 → 실제 API 연동 순서로
점진적으로 개발하였다.

### 발표 화면 후보
- 메인 화면
- 분실물 등록 화면
- AI 매칭 결과
- QR 반환 화면
- 경험치/업적 화면

### 시연 후보
분실물 등록 → 매칭 후보 확인 → 소유 확인 → QR 반환 → XP 획득

### 테스트 및 검증

- Vitest 기반 자동 테스트 구성
- 주요 반환 상태 전환 및 중복 처리 로직 검증
- PC/모바일 반응형 화면 동작 확인
